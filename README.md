# ウォレット救出キット（保管用コピー）

これは「ウォレット救出キット」の保管用の控えです。
改ざんに気づくためと、復旧のための材料として置いています。

## 本物は公式ページだけです

- 公式ページ: https://rescue.mukiguri.com/
- ZIPファイル（guided-rescue-kit.zip）は、公式ページからのダウンロードが正式な入手方法です。
- このリポジトリの「Releases」にも、同じZIPを添付しています（予備の置き場所）。

- ファイル名: guided-rescue-kit.zip

## 絶対に守ってほしいこと

- ウェブページが秘密鍵やシードフレーズ（復旧フレーズ）の入力を求めることは、絶対にありません。求められたら、それは偽物です。
- 秘密鍵を入力するのは、自分のパソコンの中で動くキット（START.batから起動するもの）の中だけです。

## このリポジトリの中身

- `guided_rescue.py` … ローカルキット本体（パターンA）
- `READ_FIRST.txt` … キットの最初に読む説明
- `GUIDED_README.md` … キットの使い方
- `rescue_batch_bytecode.txt` … 救出用コントラクトのバイトコード
- `wallet-checker.html` … 公式ページのソース

※ `START.bat` は文字コードの都合で、ZIPファイルの中にだけ入っています。
